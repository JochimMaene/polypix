# Communications Constellation Availability

This example asks a communications question: **how many satellites can each
ground cell see at the same time?** It models a Starlink-like Walker
constellation of 500 satellites for one hour and maps the mean simultaneous
satellite count above a 25° minimum-elevation mask.

The map and measurements are generated by executing the
[complete example source][source] during every clean documentation build.
There is no committed output image or copied result to drift from the code.

```python exec="on" html="on" id="communication-constellation-result"
from examples.communication_constellation import render_documentation

print(render_documentation())
```

## What Is Being Counted

The satellite positions are sampled once per minute, including both ends of the
one-hour window. At each of the 61 timestamps, a cell counts one satellite when
its center is inside that satellite's service footprint. The plotted value is
the mean of those 61 instantaneous counts, not the number of distinct
satellites seen at any point during the hour.

A circular field of regard is appropriate for this communications example: a
25° minimum elevation defines a spherical cap around each sub-satellite point.
The cap radius is derived from the 550 km orbital altitude and spherical Earth,
then represented by an inscribed 16-sided convex spherical polygon for
`cover_footprint()`.

## Simulation Model

| Parameter | Value |
| --- | ---: |
| Satellites | 500 |
| Orbital planes | 20 |
| Orbit | Circular, 550 km |
| Inclination | 53° |
| Duration | 1 hour |
| Sampling cadence | 60 seconds |
| Time samples | 61 |
| Minimum elevation | 25° |
| Service-footprint vertices | 16 |
| HEALPix resolution | 6 |
| HEALPix cells | 49,152 |

The orbit is an idealized Walker-like distribution on a spherical rotating
Earth. It is designed to demonstrate coverage throughput, not reproduce an
operational Starlink shell.

## Cover Service Footprints

All 500 footprints at one timestamp are covered as one dense batch. The result
is immediately reduced with `bincount()` and discarded before the next
timestamp, bounding peak memory independently of the full 30,500-footprint
workload:

```python title="examples/communication_constellation.py"

```

The live table separates orbit and footprint generation, Polypix coverage,
availability reduction, complete numerical analysis, and plotting. These are
single wall-clock measurements from the documentation builder, not controlled
benchmarks.
