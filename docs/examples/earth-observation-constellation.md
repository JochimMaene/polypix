# Earth-Observation Constellation Coverage

This example asks two Earth-observation questions: **how many distinct
observations does each cell receive, and how long is the revisit gap?** It
models ten satellites over ten days using swept one-minute sensor intervals.

Both maps and all measurements are generated by executing the
[complete example source][source] during every clean documentation build, so
the documentation cannot drift from the runnable implementation.

## What Is Being Counted

For every pair of adjacent one-minute samples, `cover_strip()` covers the swept
spherical quadrilateral:

```text
[left[i], right[i], right[i + 1], left[i + 1]]
```

This fills the motion between samples. It does not approximate the moving EO
sensor with disconnected circular footprints.

Consecutive covered intervals for the same satellite and cell form one
observation. A later pass starts another observation, while observations from
different satellites count separately.

For revisit time, observations from all satellites are merged. Overlapping or
consecutive hits form one constellation access window. Revisit is the uncovered
gap from the end of one access window to the beginning of the next. The map
shows the mean gaps measured during the ten days and omits cells with fewer than
two access windows. Leading and trailing gaps outside the analysis window are
not included, and all boundaries are quantized to one minute.

## Simulation Model

| Parameter | Value |
| --- | ---: |
| Satellites | 10 |
| Orbital planes | 5 |
| Orbit | Circular, 550 km |
| Inclination | 53° |
| Duration | 10 days |
| Edge-sampling cadence | 60 seconds |
| Edge samples per satellite | 14,401 |
| Swept intervals per satellite | 14,400 |
| Ground-swath half-width | 7.5° |
| HEALPix resolution | 6 |
| HEALPix cells | 49,152 |

The compact orbit model uses a spherical rotating Earth and constant spherical
ground half-width. Operational analysis should supply propagated sensor edges.

uses integer last-seen timestamps to detect observation starts, merge
simultaneous satellite hits, and accumulate revisit gaps in one chronological
pass:
