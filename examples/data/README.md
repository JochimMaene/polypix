# Example data

`starlink-2026-07-29.tle` is a snapshot of the CelesTrak Starlink group fetched
in three-line element format on 2026-07-29. It is committed so the communication
case study is reproducible and does not download data during documentation
builds.

Source: <https://celestrak.org/NORAD/elements/gp.php?GROUP=STARLINK&FORMAT=TLE>

`central-europe-borders.json` is an offline extract of the public-domain
[Natural Earth 1:50m Admin 0 Countries](https://www.naturalearthdata.com/downloads/50m-cultural-vectors/)
dataset, version 5.1.2. It contains only the country outlines visible in the
Germany example map.

`sentinel-2-2026-08-24.tle` holds the three Sentinel-2 spacecraft, taken from the
CelesTrak Earth-resources group on 2026-08-24 and committed for the same reason.

Source: <https://celestrak.org/NORAD/elements/gp.php?GROUP=resource&FORMAT=TLE>
